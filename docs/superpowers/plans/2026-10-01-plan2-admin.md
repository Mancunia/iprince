# Plan 2: Professions, Form Builder, Staff Invites, Cleanup Job — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Staff manage professions and publish versioned application forms without SQL; the owner invites and removes editors; abandoned applications and orphaned uploads are deleted automatically (pre-production GDPR gate).

**Architecture:** One migration adds draft/publish and cleanup SQL functions. Admin features follow Plan 1's pattern: `features/<domain>/` holds pure tested logic, `admin-queries.ts` (server reads with the admin's session), `admin-actions.ts` (server actions returning `ActionResult`, `requireAdmin` first). The cleanup job is a `GET /api/cron/cleanup-applications` route scheduled by Vercel Cron and guarded by `CRON_SECRET`. Invites use the Supabase Auth admin API (service role, owner-gated) and a token-hash confirm route.

**Tech Stack:** Next 16.3 (App Router, server actions, route handlers), React 19, StyleX, next-intl 4, Supabase (Postgres, Auth, Storage) via `@supabase/ssr` + `@supabase/supabase-js`, zod 4, Vitest, pgTAP, Playwright, `@vercel/config`.

**Spec:** `docs/superpowers/specs/2026-09-30-plan2-admin-design.md` (parent: `docs/superpowers/specs/2026-09-30-foundation-design.md`).

## Global Constraints

- Branch `feat/foundation`; never push or merge without the user asking.
- Every admin server action calls `requireAdmin(locale)` (or `requireOwner(locale)`) **before** parsing any other input.
- Admin reads/writes use `createServerSupabase()` (the admin's session, RLS applies). The service role is used only by public submissions, the cleanup job and owner-gated `auth.admin.*` calls.
- Abandoned retention: **24 hours** after `created_at`. Cron schedule: **`0 3 * * *`** (daily; hourly later on Vercel Pro).
- `CRON_SECRET`: at least 32 characters; compared in constant time.
- New staff are always `editor`. Only the owner sees `/admin/team`; editors get 404.
- Passwords: minimum 12 characters (matches `minimum_password_length = 12` in `supabase/config.toml`).
- Every user-visible string goes into both `src/i18n/messages/en.json` and `de.json`.
- Logs never contain personal data (no names, emails, file names).
- Next.js here is v16 — read the relevant file in `node_modules/next/dist/docs/` before using an API you are unsure about (AGENTS.md).
- Commit messages end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- `npm run check` passes before every commit (needs `npx supabase start`).

## Deviations from the spec (agreed during planning)

- **No sections editor.** `DynamicFields` never renders `sections`, so editing them has no visible effect. The builder keeps any existing `sections`/`section` values untouched. Revisit when the apply page renders sections.
- **Invite link** is built from the invite's `redirectTo` (`<origin>/api/auth/confirm?next=/<locale>/admin/set-password`) so the session cookie lands on the origin the owner used (localhost vs 127.0.0.1). The email template link is `{{ .RedirectTo }}&token_hash={{ .TokenHash }}&type=invite`.
- **Set-password page lives inside `admin/(protected)/`**: the invited user already has a session and an `admins` row when they arrive.
- **Form status** gains a fourth state, "Draft only" (draft exists, nothing published).

## Review Focus

1. **Storage refuses to delete a listed orphan** (e.g. already gone) → the cleanup loop must stop, not spin until the time budget runs out. Test: `cleanup.test.ts` "stops when a batch removes nothing".
2. **Two admins edit the same draft** → the second save/publish gets "changed by someone else", never a silent overwrite. Test: pgTAP "publish with a stale updated_at raises P0002"; save uses the same `updated_at` filter.
3. **A crafted invite link** (`next=https://evil.example` or `//evil.example`) → redirect stays on an admin path of this site. Test: `paths.test.ts` `safeNextPath` cases.
4. **Deleting a profession that has applications** → refused with "deactivate instead"; deleting one without applications removes its form versions. Test: pgTAP delete cases.
5. **German labels with umlauts, digits or reserved words** (`Größe`, `2. Sprache`, `Email`) → the suggested key is valid and unique. Test: `model.test.ts` `suggestKey` cases.

```sql
-- Plan 2: form drafts and publishing, abandoned-application cleanup.

-- At most one unpublished draft per profession.
create unique index profession_forms_one_draft on public.profession_forms (profession_id) where published_at is null;

-- Returns the profession's draft, creating version N+1 from the live schema if there is none.
-- security invoker: RLS still requires is_admin().
create or replace function public.start_form_draft(p_profession_id uuid) returns uuid
language plpgsql security invoker set search_path = '' as $$
declare
  v_id uuid;
begin
  insert into public.profession_forms (profession_id, version, schema)
  select p.id,
         coalesce((select max(f.version) from public.profession_forms f where f.profession_id = p.id), 0) + 1,
         coalesce((select f.schema from public.profession_forms f where f.id = p.current_form_id), '{"fields": []}'::jsonb)
  from public.professions p
  where p.id = p_profession_id
  on conflict (profession_id) where published_at is null do nothing
  returning id into v_id;

  if v_id is null then
    select id into v_id from public.profession_forms where profession_id = p_profession_id and published_at is null;
  end if;
  if v_id is null then
    raise exception 'profession not found' using errcode = 'P0002';
  end if;
  return v_id;
end $$;

-- Publishes a draft and makes it the profession's current form, atomically.
-- Raises P0002 when the draft is gone, already published, or changed since the caller loaded it.
create or replace function public.publish_form_draft(p_form_id uuid, p_expected_updated_at timestamptz) returns void
language plpgsql security invoker set search_path = '' as $$
declare
  v_profession_id uuid;
begin
  update public.profession_forms set published_at = now()
  where id = p_form_id and published_at is null and updated_at = p_expected_updated_at
  returning profession_id into v_profession_id;
  if v_profession_id is null then
    raise exception 'draft is missing or stale' using errcode = 'P0002';
  end if;
  update public.professions set current_form_id = p_form_id where id = v_profession_id;
end $$;

revoke execute on function public.start_form_draft(uuid) from public, anon;
revoke execute on function public.publish_form_draft(uuid, timestamptz) from public, anon;
grant execute on function public.start_form_draft(uuid) to authenticated;
grant execute on function public.publish_form_draft(uuid, timestamptz) to authenticated;

-- Uploads older than the cutoff that no submitted application references.
create or replace function public.orphaned_application_objects(p_cutoff timestamptz, p_limit int) returns setof text
language sql stable security definer set search_path = '' as $$
  select o.name from storage.objects o
  where o.bucket_id = 'applications'
    and o.created_at < p_cutoff
    and not exists (select 1 from public.application_files f where f.storage_path = o.name)
  order by o.created_at
  limit p_limit;
$$;

-- Applications that were started but never finalized before the cutoff.
create or replace function public.delete_abandoned_applications(p_cutoff timestamptz) returns int
language sql security definer set search_path = '' as $$
  with deleted as (
    delete from public.applications where submitted_at is null and created_at < p_cutoff returning 1
  )
  select count(*)::int from deleted;
$$;

revoke execute on function public.orphaned_application_objects(timestamptz, int) from public, anon, authenticated;
revoke execute on function public.delete_abandoned_applications(timestamptz) from public, anon, authenticated;
grant execute on function public.orphaned_application_objects(timestamptz, int) to service_role;
grant execute on function public.delete_abandoned_applications(timestamptz) to service_role;
```

```ts
import type { ServiceClient } from "@/lib/supabase/service";

export const ABANDONED_AFTER_MS = 24 * 60 * 60 * 1000;
const BATCH_SIZE = 500;
const BUCKET = "applications";

export type CleanupResult = { filesDeleted: number; applicationsDeleted: number; complete: boolean };

/**
 * Deletes uploads no submitted application references, then applications never submitted, both older than 24 h.
 * Every step is idempotent: a failed or partial run is finished by the next one.
 */
export async function cleanupAbandoned(supabase: ServiceClient, now: Date, budgetMs = 50_000): Promise<CleanupResult> {
  const started = Date.now();
  const cutoff = new Date(now.getTime() - ABANDONED_AFTER_MS).toISOString();
  let filesDeleted = 0;
  let complete = false;

  while (Date.now() - started < budgetMs) {
    const { data: names, error } = await supabase.rpc("orphaned_application_objects", { p_cutoff: cutoff, p_limit: BATCH_SIZE });
    if (error) throw error;
    if (names.length === 0) {
      complete = true;
      break;
    }
    const { data: removed, error: removeError } = await supabase.storage.from(BUCKET).remove(names);
    if (removeError) throw removeError;
    filesDeleted += removed.length;
    if (removed.length === 0) break; // Storage refused every name; the next run retries.
  }

  const { data: applicationsDeleted, error } = await supabase.rpc("delete_abandoned_applications", { p_cutoff: cutoff });
  if (error) throw error;
  return { filesDeleted, applicationsDeleted, complete };
}
```

```ts
export function fieldErrorsOf(issues: readonly { path: readonly PropertyKey[] }[]): FieldErrors {
```

```ts
export const professionInput = z.object({
  slug: z.string().trim().max(60).regex(/^[a-z0-9]+(-[a-z0-9]+)*$/),
  nameDe: z.string().trim().min(1).max(120),
  nameEn: z.string().trim().max(120),
  summaryDe: z.string().trim().max(500),
  summaryEn: z.string().trim().max(500),
  icon: z.string().regex(/^[a-z0-9-]+$/),
  isActive: z.boolean(),
  isFeatured: z.boolean(),
  sortOrder: z.coerce.number().int().min(0).max(10_000),
  openPositions: z.coerce.number().int().min(0).max(100_000),
});
export type ProfessionInput = z.infer<typeof professionInput>;

export const EMPTY_PROFESSION: ProfessionInput = {
  slug: "", nameDe: "", nameEn: "", summaryDe: "", summaryEn: "", icon: "briefcase",
  isActive: false, isFeatured: false, sortOrder: 0, openPositions: 0,
};

/** Reads ProfessionForm's FormData. Checkboxes are present only when ticked. */
export function readProfessionForm(formData: FormData) {
  const text = (key: string) => String(formData.get(key) ?? "");
  return professionInput.safeParse({
    slug: text("slug"),
    nameDe: text("nameDe"),
    nameEn: text("nameEn"),
    summaryDe: text("summaryDe"),
    summaryEn: text("summaryEn"),
    icon: text("icon"),
    isActive: formData.get("isActive") === "on",
    isFeatured: formData.get("isFeatured") === "on",
    sortOrder: text("sortOrder") || "0",
    openPositions: text("openPositions") || "0",
  });
}

export function toProfessionRow(input: ProfessionInput) {
  return {
    slug: input.slug,
    name: { de: input.nameDe, en: input.nameEn },
    summary: { de: input.summaryDe, en: input.summaryEn },
    icon: input.icon,
    is_active: input.isActive,
    is_featured: input.isFeatured,
    sort_order: input.sortOrder,
    open_positions: input.openPositions,
  };
}

/** A profession can go live only with a published form, otherwise its apply page would 404. */
export function canActivate(isActive: boolean, currentFormId: string | null): boolean {
  return !isActive || currentFormId !== null;
}

export type FormStatus = { kind: "none" } | { kind: "draft_only" } | { kind: "live"; version: number; draft: boolean };

export function formStatus(
  forms: { id: string; version: number; published_at: string | null }[],
  currentFormId: string | null,
): FormStatus {
  const draft = forms.some((f) => f.published_at === null);
  const current = forms.find((f) => f.id === currentFormId);
  if (current) return { kind: "live", version: current.version, draft };
  return draft ? { kind: "draft_only" } : { kind: "none" };
}
```

```ts
import { revalidatePath } from "next/cache";

import { z } from "zod";
import { locales } from "@/i18n/config";
import { requireAdmin } from "@/features/admin-auth/session";

import { createServerSupabase } from "@/lib/supabase/server";
import { canActivate, readProfessionForm, toProfessionRow } from "./admin";
import { listIconNames } from "./admin-queries";

type Result = ActionResult<null>;

const localeOf = (formData: FormData) => z.enum(locales).catch("en").parse(formData.get("locale"));

function dbFailure(error: PostgrestError, what: string): Result {
  if (error.code === "23505") return fail("invalid", { slug: ["taken"] });
  console.error(`${what} failed`, error);
  return fail("server_error");
}

async function parse(formData: FormData) {
  const parsed = readProfessionForm(formData);
  if (!parsed.success) return { error: fail("invalid", fieldErrorsOf(parsed.error.issues)) } as const;
  if (!(await listIconNames()).includes(parsed.data.icon)) return { error: fail("invalid", { icon: ["invalid"] }) } as const;
  return { data: parsed.data } as const;
}

export async function createProfession(_prev: Result | null, formData: FormData): Promise<Result> {
  const locale = localeOf(formData);
  await requireAdmin(locale);
  const parsed = await parse(formData);
  if (parsed.error) return parsed.error;

  const supabase = await createServerSupabase();
  const { data, error } = await supabase
    .from("professions")
    .insert({ ...toProfessionRow(parsed.data), is_active: false })
    .select("id")
    .single();
  if (error) return dbFailure(error, "create profession");
  revalidatePath("/", "layout");
  redirect(`/${locale}/admin/professions/${data.id}/form`);
}

export async function updateProfession(_prev: Result | null, formData: FormData): Promise<Result> {
  const locale = localeOf(formData);
  await requireAdmin(locale);
  const id = z.guid().safeParse(formData.get("id"));
  if (!id.success) return fail("invalid");
  const parsed = await parse(formData);
  if (parsed.error) return parsed.error;

  const supabase = await createServerSupabase();
  const { data: current, error: readError } = await supabase
    .from("professions")
    .select("current_form_id")
    .eq("id", id.data)
    .maybeSingle();
  if (readError) return dbFailure(readError, "read profession");
  if (!current) return fail("not_found");
  if (!canActivate(parsed.data.isActive, current.current_form_id)) return fail("invalid", { isActive: ["form_required"] });

  const { data, error } = await supabase.from("professions").update(toProfessionRow(parsed.data)).eq("id", id.data).select("id");
  if (error) return dbFailure(error, "update profession");
  if (data.length === 0) return fail("not_found");
  revalidatePath("/", "layout");
  return ok(null);
}
```

```ts
import { formDefinition, RESERVED_KEYS, type FormDefinition, type FormField } from "../definition";

export type FieldType = FormField["type"];
/** Validation messages keyed by dotted path, e.g. "fields.3.label.de". */
export type BuilderErrors = Record<string, string[]>;

const CHOICE_TYPES: readonly FieldType[] = ["select", "multiselect", "radio"];
const emptyText = () => ({ de: "", en: "" });

export function moveItem<T>(list: readonly T[], index: number, delta: -1 | 1): T[] {
  const target = index + delta;
  const next = [...list];
  if (index < 0 || index >= list.length || target < 0 || target >= list.length) return next;
  [next[index], next[target]] = [next[target], next[index]];
  return next;
}

export function removeAt<T>(list: readonly T[], index: number): T[] {
  return list.filter((_, i) => i !== index);
}

export function selectedAfterMove(selected: number | null, index: number, delta: -1 | 1): number | null {
  if (selected === index) return index + delta;
  if (selected === index + delta) return index;
  return selected;
}

export function selectedAfterRemove(selected: number | null, index: number): number | null {
  if (selected === null || selected === index) return null;
  return selected > index ? selected - 1 : selected;
}

const UMLAUTS: Record<string, string> = { ä: "ae", ö: "oe", ü: "ue", ß: "ss" };
const MAX_BASE = 36; // leaves room for a "_NN" suffix within the 40-character key limit

const trimKey = (key: string) => key.slice(0, MAX_BASE).replace(/_+$/, "");

/** snake_case answer key from a label; never reserved, never already used. */
export function suggestKey(label: string, existingKeys: readonly string[]): string {
  const slug = trimKey(
    label
      .toLowerCase()
      .replace(/[äöüß]/g, (c) => UMLAUTS[c])
      .normalize("NFKD")
      .replace(/[̀-ͯ]/g, "")
      .replace(/[^a-z0-9]+/g, "_")
      .replace(/^_+/, ""),
  );
  const base = slug === "" ? "field" : /^[a-z]/.test(slug) ? slug : trimKey(`f_${slug}`);
  const taken = new Set([...existingKeys, ...RESERVED_KEYS]);
  if (!taken.has(base)) return base;
  for (let n = 2; ; n++) {
    const candidate = `${base}_${n}`;
    if (!taken.has(candidate)) return candidate;
  }
}

export function changeType(field: FormField, type: FieldType): FormField {
  const { options, accept, maxSizeMb, ...rest } = field;
  const next: FormField = { ...rest, type };
  if (CHOICE_TYPES.includes(type)) next.options = options?.length ? options : [{ value: "option_1", label: emptyText() }];
  if (type === "file") {
    next.accept = accept ?? ["application/pdf"];
    next.maxSizeMb = maxSizeMb ?? 10;
  }
  return next;
}

export function newField(type: FieldType, existingKeys: readonly string[]): FormField {
  return changeType({ key: suggestKey("", existingKeys), type: "text", label: emptyText(), required: false }, type);
}

export function nextOptionValue(options: readonly { value: string }[]): string {
  const used = new Set(options.map((o) => o.value));
  for (let n = 1; ; n++) if (!used.has(`option_${n}`)) return `option_${n}`;
}

export function parseAccept(text: string): string[] | undefined {
  const types = text.split(",").map((t) => t.trim()).filter(Boolean);
  return types.length > 0 ? types : undefined;
}

export function validateDefinition(input: unknown): { ok: true; data: FormDefinition } | { ok: false; errors: BuilderErrors } {
  const parsed = formDefinition.safeParse(input);
  if (parsed.success) return { ok: true, data: parsed.data };
  const errors: BuilderErrors = {};
  for (const issue of parsed.error.issues) (errors[issue.path.map(String).join(".")] ??= []).push(issue.message);
  return { ok: false, errors };
}

export function errorsUnder(errors: BuilderErrors, prefix: string): BuilderErrors {
  const out: BuilderErrors = {};
  for (const [key, messages] of Object.entries(errors)) {
    if (key === prefix) out[""] = messages;
    else if (key.startsWith(`${prefix}.`)) out[key.slice(prefix.length + 1)] = messages;
  }
  return out;
}

export function hasErrorsUnder(errors: BuilderErrors, prefix: string): boolean {
  return Object.keys(errorsUnder(errors, prefix)).length > 0;
}
```

```ts
import "server-only";
import { z } from "zod";
import type { LocalizedText } from "@/lib/i18n/localized";
import { createServerSupabase } from "@/lib/supabase/server";
import { formDefinition, type FormDefinition } from "./definition";

type StoredForm = { id: string; version: number; definition: FormDefinition };

export type BuilderData = {
  profession: { id: string; name: LocalizedText };
  live: StoredForm | null;
  draft: (StoredForm & { updatedAt: string }) | null;
  versions: (StoredForm & { publishedAt: string; applications: number })[];
};

const storedText = z.object({ de: z.string().default(""), en: z.string().default("") }).catch({ de: "", en: "" });

function readDefinition(id: string, schema: unknown): FormDefinition {
  const parsed = formDefinition.safeParse(schema);
  if (parsed.success) return parsed.data;
  console.error(`profession_forms ${id} has an invalid schema`, parsed.error.issues);
  return { fields: [] };
}

export async function getBuilderData(professionId: string): Promise<BuilderData | null> {
  if (!z.guid().safeParse(professionId).success) return null;
  const supabase = await createServerSupabase();
  const [profession, forms] = await Promise.all([
    supabase.from("professions").select("id, name, current_form_id").eq("id", professionId).maybeSingle(),
    supabase
      .from("profession_forms")
      .select("id, version, schema, published_at, updated_at, applications(count)")
      .eq("profession_id", professionId)
      .order("version", { ascending: false }),
  ]);
  if (profession.error) throw profession.error;
  if (forms.error) throw forms.error;
  if (!profession.data) return null;

  const stored = forms.data.map((f) => ({ ...f, definition: readDefinition(f.id, f.schema) }));
  const draftRow = stored.find((f) => f.published_at === null);
  const liveRow = stored.find((f) => f.id === profession.data.current_form_id);
  const pick = (f: (typeof stored)[number]): StoredForm => ({ id: f.id, version: f.version, definition: f.definition });

  return {
    profession: { id: profession.data.id, name: storedText.parse(profession.data.name) },
    live: liveRow ? pick(liveRow) : null,
    draft: draftRow ? { ...pick(draftRow), updatedAt: draftRow.updated_at } : null,
    versions: stored
      .filter((f) => f.published_at !== null)
      .map((f) => ({ ...pick(f), publishedAt: f.published_at!, applications: f.applications[0]?.count ?? 0 })),
  };
}
```

```ts
"use server";

import { revalidatePath } from "next/cache";
import { redirect } from "next/navigation";
import { z } from "zod";
import { locales, type Locale } from "@/i18n/config";
import { requireAdmin } from "@/features/admin-auth/session";
import type { Json } from "@/lib/supabase/database.types";
import { fail, ok, type ActionResult } from "@/lib/result";
import { createServerSupabase } from "@/lib/supabase/server";
import { validateDefinition } from "./builder/model";
import type { FormDefinition } from "./definition";

export type DraftInput = { locale: Locale; formId: string; expectedUpdatedAt: string; definition: unknown };
type Saved = ActionResult<{ updatedAt: string }>;

const draftRef = z.object({ formId: z.guid(), expectedUpdatedAt: z.string().min(1).max(64) });
const localeOf = (value: unknown) => z.enum(locales).catch("en").parse(value);

export async function startFormDraft(formData: FormData): Promise<void> {
  const locale = localeOf(formData.get("locale"));
  await requireAdmin(locale);
  const professionId = z.guid().parse(formData.get("professionId"));
  const supabase = await createServerSupabase();
  const { error } = await supabase.rpc("start_form_draft", { p_profession_id: professionId });
  if (error) {
    console.error("start_form_draft failed", error);
    throw new Error("Could not start a draft.");
  }
  revalidatePath(`/${locale}/admin/professions`, "layout");
  redirect(`/${locale}/admin/professions/${professionId}/form`);
}

async function writeDraft(formId: string, expectedUpdatedAt: string, definition: FormDefinition): Promise<Saved> {
  const supabase = await createServerSupabase();
  const { data, error } = await supabase
    .from("profession_forms")
    .update({ schema: definition as unknown as Json })
    .eq("id", formId)
    .is("published_at", null)
    .eq("updated_at", expectedUpdatedAt)
    .select("updated_at");
  if (error) {
    console.error("save draft failed", error);
    return fail("server_error");
  }
  return data.length === 1 ? ok({ updatedAt: data[0].updated_at }) : fail("stale");
}

async function prepare(input: DraftInput) {
  const locale = localeOf(input?.locale);
  await requireAdmin(locale);
  const ref = draftRef.safeParse(input);
  if (!ref.success) return { error: fail("invalid") } as const;
  const definition = validateDefinition(input.definition);
  if (!definition.ok) return { error: fail("invalid", definition.errors) } as const;
  return { locale, ...ref.data, definition: definition.data } as const;
}

export async function saveFormDraft(input: DraftInput): Promise<Saved> {
  const prepared = await prepare(input);
  if ("error" in prepared) return prepared.error;
  const saved = await writeDraft(prepared.formId, prepared.expectedUpdatedAt, prepared.definition);
  if (saved.ok) revalidatePath(`/${prepared.locale}/admin/professions`, "layout");
  return saved;
}

export async function publishFormDraft(input: DraftInput): Promise<Saved> {
  const prepared = await prepare(input);
  if ("error" in prepared) return prepared.error;
  if (prepared.definition.fields.length === 0) return fail("empty_form");
  const saved = await writeDraft(prepared.formId, prepared.expectedUpdatedAt, prepared.definition);
  if (!saved.ok) return saved;

  const supabase = await createServerSupabase();
  const { error } = await supabase.rpc("publish_form_draft", { p_form_id: prepared.formId, p_expected_updated_at: saved.data.updatedAt });
  if (error?.code === "P0002") return fail("stale");
  if (error) {
    console.error("publish_form_draft failed", error);
    return fail("server_error");
  }
  revalidatePath("/", "layout");
  return saved;
}

export async function discardFormDraft(input: { locale: Locale; formId: string }): Promise<ActionResult<null>> {
  const locale = localeOf(input?.locale);
  await requireAdmin(locale);
  const formId = z.guid().safeParse(input?.formId);
  if (!formId.success) return fail("invalid");
  const supabase = await createServerSupabase();
  const { data, error } = await supabase.from("profession_forms").delete().eq("id", formId.data).is("published_at", null).select("id");
  if (error) {
    console.error("discard draft failed", error);
    return fail("server_error");
  }
  if (data.length === 0) return fail("not_found");
  revalidatePath(`/${locale}/admin/professions`, "layout");
  return ok(null);
}
```

```tsx
"use client";

import { useTranslations } from "next-intl";
import { useRouter } from "next/navigation";
import { useEffect, useState, useTransition } from "react";
import type { Locale } from "@/i18n/config";
import type { ActionResult } from "@/lib/result";
import { Button } from "@/ui/Button";
import { Stack } from "@/ui/Stack";
import { Text } from "@/ui/Text";
import { discardFormDraft, publishFormDraft, saveFormDraft } from "../admin-actions";
import type { FormDefinition, FormField } from "../definition";
import { FieldEditor } from "./FieldEditor";
import { FieldList } from "./FieldList";
import { FormPreview } from "./FormPreview";
import {
  errorsUnder, hasErrorsUnder, moveItem, newField, removeAt, selectedAfterMove, selectedAfterRemove, validateDefinition,
  type BuilderErrors,
} from "./model";

type Props = { locale: Locale; formId: string; version: number; initialDefinition: FormDefinition; initialUpdatedAt: string };
type Message = { tone: "success" | "danger"; text: string };

export function FormBuilder({ locale, formId, version, initialDefinition, initialUpdatedAt }: Props) {
  const t = useTranslations("admin.forms");
  const router = useRouter();
  const [definition, setDefinition] = useState(initialDefinition);
  const [updatedAt, setUpdatedAt] = useState(initialUpdatedAt);
  const [selected, setSelected] = useState<number | null>(initialDefinition.fields.length > 0 ? 0 : null);
  const [errors, setErrors] = useState<BuilderErrors>({});
  const [dirty, setDirty] = useState(false);
  const [message, setMessage] = useState<Message | null>(null);
  const [pending, startTransition] = useTransition();

  useEffect(() => {
    if (!dirty) return;
    const warn = (event: BeforeUnloadEvent) => event.preventDefault();
    window.addEventListener("beforeunload", warn);
    return () => window.removeEventListener("beforeunload", warn);
  }, [dirty]);

  const fields = definition.fields;
  const keys = fields.map((f) => f.key);

  function update(next: FormField[], nextSelected: number | null) {
    setDefinition({ ...definition, fields: next });
    setSelected(nextSelected);
    setDirty(true);
    setMessage(null);
  }

  function fail(code: string | undefined, fieldErrors: BuilderErrors = {}) {
    setErrors(fieldErrors);
    setMessage({ tone: "danger", text: t(`errors.${code ?? "server_error"}`) });
  }

  function accept(result: ActionResult<{ updatedAt: string }>, successText: string): boolean {
    if (!result.ok) {
      fail(result.formError, result.fieldErrors);
      return false;
    }
    setUpdatedAt(result.data.updatedAt);
    setErrors({});
    setDirty(false);
    setMessage({ tone: "success", text: successText });
    return true;
  }

  function submit(kind: "save" | "publish") {
    const check = validateDefinition(definition);
    if (!check.ok) return fail("invalid", check.errors);
    startTransition(async () => {
      const input = { locale, formId, expectedUpdatedAt: updatedAt, definition };
      if (kind === "save") {
        accept(await saveFormDraft(input), t("saved"));
      } else if (accept(await publishFormDraft(input), t("published"))) {
        router.refresh();
      }
    });
  }

  function discard() {
    if (!window.confirm(t("confirmDiscard"))) return;
    startTransition(async () => {
      const result = await discardFormDraft({ locale, formId });
      if (!result.ok) return fail(result.formError);
      setDirty(false);
      router.refresh();
    });
  }

  const field = selected === null ? undefined : fields[selected];

  return (
    <Stack gap="lg">
      <Text as="h2" size="lg">{t("draftTitle", { version })}</Text>
      <FieldList
        fields={fields}
        selected={selected}
        locale={locale}
        hasErrors={(i) => hasErrorsUnder(errors, `fields.${i}`)}
        onSelect={setSelected}
        onMove={(i, delta) => update(moveItem(fields, i, delta), selectedAfterMove(selected, i, delta))}
        onRemove={(i) => update(removeAt(fields, i), selectedAfterRemove(selected, i))}
        onAdd={(type) => update([...fields, newField(type, keys)], fields.length)}
      />
      {field && selected !== null ? (
        <FieldEditor
          key={`${selected}-${field.type}`}
          field={field}
          index={selected}
          otherKeys={keys.filter((_, i) => i !== selected)}
          errors={errorsUnder(errors, `fields.${selected}`)}
          onChange={(next) => update(fields.map((f, i) => (i === selected ? next : f)), selected)}
        />
      ) : null}
      {message ? <Text role={message.tone === "success" ? "status" : "alert"} tone={message.tone}>{message.text}</Text> : null}
      <Stack direction="row" gap="sm">
        <Button variant="secondary" disabled={pending} onClick={() => submit("save")}>{t("saveDraft")}</Button>
        <Button disabled={pending} onClick={() => submit("publish")}>{t("publish")}</Button>
        <Button variant="secondary" disabled={pending} onClick={discard}>{t("discardDraft")}</Button>
      </Stack>
      <Text as="h2" size="lg">{t("preview")}</Text>
      <FormPreview definition={definition} initialLocale={locale} />
    </Stack>
  );
}
```

Note: removing a field shifts later indexes, so existing `errors` would point at the wrong rows. That is acceptable: `update` clears the message, and the next save/publish recomputes errors. Do not try to re-index errors.

```ts
const localeOf = (formData: FormData) => z.enum(locales).catch("en").parse(formData.get("locale"));

export async function inviteEditor(_prev: Result | null, formData: FormData): Promise<Result> {
  const locale = localeOf(formData);
  await requireOwner(locale);
  const parsed = inviteInput.safeParse({ email: formData.get("email"), displayName: formData.get("displayName") });
  if (!parsed.success) return fail("invalid", fieldErrorsOf(parsed.error.issues));

  // Next checks that server-action requests come from this host, so Origin is trustworthy here.
  const origin = (await headers()).get("origin");
  if (!origin) return fail("server_error");

  const admin = authAdmin();
  const { data, error } = await admin.inviteUserByEmail(parsed.data.email, { redirectTo: inviteRedirectUrl(origin, locale) });
  if (error) {
    if (error.code === "email_exists" || error.status === 422) return fail("invalid", { email: ["exists"] });
    console.error("invite failed", error.code ?? error.status);
    return fail("server_error");
  }

  // Insert with the owner's session so RLS (owner-only writes on admins) still applies.
  const supabase = await createServerSupabase();
  const { error: insertError } = await supabase
    .from("admins")
    .insert({ user_id: data.user.id, role: "editor", display_name: parsed.data.displayName });
  if (insertError) {
    console.error("admins insert failed", insertError.code);
    await admin.deleteUser(data.user.id); // no auth user without an admins row
    return fail("server_error");
  }
  revalidatePath(`/${locale}/admin/team`);
  return ok(null);
}

export async function removeEditor(_prev: Result | null, formData: FormData): Promise<Result> {
  const locale = localeOf(formData);
  const owner = await requireOwner(locale);
  const userId = z.guid().safeParse(formData.get("userId"));
  if (!userId.success) return fail("invalid");

  const supabase = await createServerSupabase();
  const { data: target, error } = await supabase.from("admins").select("user_id, role").eq("user_id", userId.data).maybeSingle();
  if (error) {
    console.error("read admin failed", error.code);
    return fail("server_error");
  }
  if (!target) return fail("not_found");
  if (!canRemove({ userId: target.user_id, role: target.role }, owner.userId)) return fail("not_allowed");

  // Deleting the auth user cascades to admins; getAdminSession() then rejects their next request.
  const { error: deleteError } = await authAdmin().deleteUser(target.user_id);
  if (deleteError) {
    console.error("delete user failed", deleteError.code ?? deleteError.status);
    return fail("server_error");
  }
  revalidatePath(`/${locale}/admin/team`);
  return ok(null);
```

```ts
// Under /api so the i18n proxy leaves it alone. verifyOtp sets the session cookies via cookies(),

export async function GET(request: NextRequest) {
  const params = request.nextUrl.searchParams;
  const next = safeNextPath(params.get("next"));
```
